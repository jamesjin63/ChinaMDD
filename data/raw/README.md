# Input data (not included)

Place the source files here before running the code. They are not redistributed in this repository.

| Folder | Content | Source |
|---|---|---|
| `CHARLS/CHARLS2011/raw_dta/`, `CHARLS/CHARLS2013/raw_dta/`, … `CHARLS/CHARLS2026/raw_dta/` | CHARLS public-release `.dta` files of each wave (2011, 2013, 2015, 2018, 2020, 2021–2023) | China Health and Retirement Longitudinal Study, https://charls.pku.edu.cn (registration required) |
| `GBD2023/China_mental_disorders_GBD2023_1990_2023.csv` | GBD 2023 prevalence for China (location 6), causes 558, 567, 568, 571; sexes 1–3; 5-year age groups ≥45; years 1990–2023; metrics number and rate | GBD Results Tool, https://vizhub.healthdata.org/gbd-results/ |
| `WPP2024/WPP2024_PopulationByAge5GroupSex_Medium.csv.gz` | UN World Population Prospects 2024, population by 5-year age group and sex, medium variant | https://population.un.org/wpp/ |
